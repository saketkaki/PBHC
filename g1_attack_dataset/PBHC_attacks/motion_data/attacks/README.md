# G1 attack motions (PBHC format)

This folder has 480 clips: 60 each of jab, cross, lead_hook, rear_hook, lead_uppercut, rear_uppercut,
body_shot and calf_kick. They are generated by `attack_gen/generate_attacks.py --per_attack 60 --seed 0`.

- `<attack>/<attack>_NNNN.pkl`: one clip per file. Pass a single file to PBHC's motion-tracking
  setup, or pass a class folder to general tracking.
- `attacks_all.pkl`: all clips in one file, for general tracking or `attack_gen/attack_library.py`.
- `index.json` / `index.csv`: labels, onset/impact/recovery frames, targets and quality metrics.
- `defender_guard.pkl`: the guard pose of the defender the attacks are aimed at.
- `previews/`: one GIF per attack, plus `contact_sheet.png`.

See `attack_gen/README.md` for the format, frames and the defender-training recipe.
